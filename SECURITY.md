# Security Policy

## Scope

This public repository contains RSL Drafter release packages and product information. The application source code is not published here. The current public release is v0.1.3, with documented compatibility for Windows 11 x64, the standard Plarium Play installation, and RAID: Shadow Legends 11.80.0. Check the [latest release](https://github.com/Nanaconda38/RSL-Drafter/releases/latest) before reporting, and include the app version, RAID build, and Windows version.

## Reporting

Use the repository's [Security page](https://github.com/Nanaconda38/RSL-Drafter/security), then select **Report a vulnerability** to send a security report through GitHub's private reporting flow. Do not post vulnerability details or proof of concept in public issues, pull requests, discussions, Discord, screenshots, or logs. Never include passwords, tokens, account identifiers, verification or invitation links, callback links, or unredacted diagnostics.

For ordinary product bugs, use the [public issue tracker](https://github.com/Nanaconda38/RSL-Drafter/issues) and remove private information before posting. Do not include a vulnerability in a public bug report.

No bounty or response-time commitment is offered.
